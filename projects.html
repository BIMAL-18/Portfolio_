AI-Driven Event Management & Recommendation Platform

SmartEvent Nepal is a full-stack event management platform designed to simplify event discovery, registration, ticketing, and event organization.   • Vite
  • Tailwind CSS
  • Node.js
  • Express.js
  • MongoDB
  • Mongoose
  • Socket.IO
  • JWT

// features
Personalized event recommendations, event discovery, event creation and management, attendee registration, Early Bird / Student / Regular / VIP tickets, QR ticket generation and verification, eSewa and Khalti payment integration, role-based access, organizer dashboards, notifications, certificates and private events.

CivicTrack Nepal

Transparent Local Development Project Monitoring and Citizen Accountability System

A digital platform designed to improve transparency and accountability in local development projects. Citizens can monitor infrastructure activities, explore project information, submit complaints with supporting evidence, and track progress. Authorized officials manage project records, budgets, updates, and complaints.

  • React.js
  • Vite
  • Tailwind CSS
  • Leaflet
  • Node.js
  • Express.js
  • MongoDB
  • Mongoose
  • JWT
  • QR Code

// features
Project monitoring, citizen and official dashboards, budget tracking, complaints with evidence uploads, project progress tracking, GIS visualization, QR verification, role-based authentication, and audit trail.
