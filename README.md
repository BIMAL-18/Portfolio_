# Static portfolio (HTML/CSS/JS)
Open `index.html` in a browser, or upload the folder to Netlify / Vercel / GitHub Pages.

## Get contact-form messages in your inbox
1. Sign up free at https://formspree.io with the email where you want messages.
2. Create a form; copy its URL (https://formspree.io/f/xxxx).
3. In `script.js`, replace `https://formspree.io/f/YOUR_FORM_ID` with it. Confirm the verification email Formspree sends you.
4. In `index.html` / `projects.html` footer, replace `YOUR_EMAIL@example.com` with your email (and the LinkedIn `#`).
